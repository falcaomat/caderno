# 🐳 Docker Básico

Mostra a versão do Docker
```bash
docker --version
```
Mostra informações do sistema e Docker
```bash
docker info
```
Mostra ajuda geral do Docker
```bash
docker help
```
Mostra uso de espaço (imagens, containers, volumes)
```bash
docker system df
```
Remove dados não utilizados (imagens, containers, redes e volumes)
```bash
docker system prune
```
Faz logout do Docker Hub
```bash
docker logout
```

Dica: Use TAB para autocompletar comandos e IDs.
